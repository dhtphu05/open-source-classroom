Cheat sheet (lệnh Git hay dùng)
-------------------------------
- git clone <url>
- git checkout -b <branch>
- git add <files>
- git commit -m "message"
- git push origin <branch>
- git fetch upstream
- git rebase upstream/main
- git merge

Công cụ khuyến nghị
-------------------
- Git client: Git CLI (bắt buộc), GitHub Desktop (tuỳ chọn)
- Code editor: VS Code (extension: GitLens)
- CI: GitHub Actions (nếu được cấu hình trong repo)
